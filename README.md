# geospatial-workflows-guide

**A hands-on training course for modern geospatial orchestration**

With practical examples in precision agriculture.

## About this course

This repository contains guides on orchestrating 
modern geospatial tools.

### What you'll learn

- Read and process geospatial data in Python
- Orchestrate modern geospatial tools (GeoPandas, Rasterio, etc.)
- Work with cloud-optimized data (COG, GeoParquet)
- OGC APIs for interoperability
